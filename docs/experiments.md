# 数学与实验定义

## Taylor 剪枝的可验证部分

给定实对称矩阵 `H`，二次目标为

```text
L(w) = 1/2 wᵀ H w + bᵀw
```

删除坐标集合对应的零填充向量为 `u`，参数变为 `w-u`。记 `g = H w + b`，则

```text
L(w-u) - L(w) = -gᵀu + 1/2 uᵀH u
| |L(w-u)-L(w)| - |gᵀu| | <= 1/2 ||H||₂ ||u||₂²
```

数值实验比较真实损失变化、一阶项与显式二阶余项；驻点示例说明 `g=0` 时，一阶分数可以为零而实际损失变化非零。一般非线性目标需要在整条参数扰动路径上满足相应平滑性假设。这里没有验证任意大网络的全局误差界。

## Wanda 的精确解释

对校准激活矩阵 `X`（行是样本、列是输入特征）与权重 `W`，删除单个权重 `W[i,j]` 的层输出扰动 Frobenius 范数恰好为

```text
|W[i,j]| * ||X[:,j]||₂
```

这是固定输入、单权重变更的层输出等式。真实的一阶损失变化还依赖反向梯度；它一般不等于上述分数。示例将等式校验与损失反例分开报告。多权重联合删除可能产生交叉项，不能直接把单权重分数相加解释为真实输出范数。

## 合成梯度重建

单条合成记录为向量 `x` 和公开目标 `y`。公开线性模型输出 `W x + b`，损失为

```text
L(W,b; x,y) = 1/2 ||W x + b - y||₂²
r = W x + b - y
g_W = r xᵀ
g_b = r
```

将权重梯度与偏置梯度连接为完整观测，再按确定性排序取前缀：

- Taylor：对应参数绝对值乘梯度绝对值。
- Magnitude：梯度绝对值。
- Random：预先固定的随机排列。

同一规则、同一记录的支持集随保留率嵌套；同分时使用稳定坐标顺序。观测包含支持集。各保留率、预算和策略使用配对的合成样本及重建初始化，以减少比较中的额外随机变化。

重建器最小化固定支持上的平方梯度误差，使用解析导数和 Adam。迭代预算是更新次数，不是 FLOPs、时间有界程序类或最优攻击预算。没有额外学习图像先验、下载数据或训练神经网络。

### 必须一起查看的对照

- **无观测基线**：`rho=0` 时无梯度匹配信号，重建保持初始化。
- **完整梯度解析对照**：若 `g_b` 非零，`x = g_Wᵀ g_b / ||g_b||₂²`。优化器失败不能推翻这一解析可恢复性。
- **零偏置梯度退化情形**：完整梯度的上述比值公式要求非零分母；零梯度情形不应用该公式。

### 当前实现的限制

重建者能看到支持集，但目标函数没有强制候选记录重新计算后仍选择出同一个支持集。当前实现没有利用全部 Top-k 排序侧信息，不能用它度量完整支持集泄漏。

数据集由随机数生成器产生，没有真实人员信息。它只演示局部数学与优化行为，不能外推真实图像、语言模型、批量训练或联邦学习中的泄漏率。增加保留率并不保证当前固定优化器的经验误差单调下降。

## 研究笔记与实现的对应关系

| 主题 | 现状 |
| --- | --- |
| 二次目标 Taylor 界、驻点行为 | 已实现数值验证 |
| 单权重 Wanda 输出扰动等式 | 已实现数值验证 |
| 线性回归梯度匹配、解析恢复对照 | 已实现合成实验 |
| 保留率 × 优化迭代次数 | 已实现扫描 |
| 量化梯度、通信 bit 计量 | 尚未实现 |
| FLOPs 对齐的攻击预算 | 尚未实现 |
| DLG/iDLG、CNN/Transformer、真实图像指标 | 尚未实现 |
| Epiplexity、条件编码器、两部码与 prequential 编码 | 理论笔记中的建议协议，未实现 |

条件 MDL 的嵌套结论依赖能够从较多观测有效投影到较少观测的假设，并需要核算投影时间与程序开销。只保留一个无序支持集不自动保证可恢复全部排名。总 MDL 的条件单调性也不推出两个分量分别单调，更不推出当前实现的固定预算误差单调。
