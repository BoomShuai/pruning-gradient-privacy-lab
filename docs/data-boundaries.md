# 数据与公开边界

默认 CLI 只生成小规模合成数值数据，不读取原始目录，不访问网络，不需要 API 密钥、真实训练数据或模型权重。公开代码在独立安装后即可运行。

`outputs/`、`private/`、`data/`、`datasets/`、虚拟环境、编译目录和常见大模型/压缩包文件由 `.gitignore` 排除。忽略规则只是防误提交措施，新增文件仍应人工检查。

公开项目不保存原始任务材料或其私人备份。删除本地项目会同时删除未提交的输出、虚拟环境和用户自行加入的数据；GitHub 只保存实际提交的文件。重要自定义结果应另行备份。

研究笔记中的大规模实验若将来实现，应另行确定数据许可、授权范围、攻击者可见信息和计算预算。当前合成示例的结果不构成真实系统的隐私保证。
